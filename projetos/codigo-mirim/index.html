A ideia

Apresentar a programação e a engenharia de software para crianças de um jeito que caiba numa aula: jogos curtos, que funcionam no celular, no tablet ou no projetor, e materiais prontos para o professor conduzir a aula e continuar o assunto depois.

Nos jogos, as crianças montam sequências de comandos, caçam bugs, programam em dupla e descobrem como um aplicativo conversa com um servidor e um banco de dados. Para os professores, a Oficina de Prompts mostra como usar o Gemini para criar atividades, histórias e até jogos para as próprias turmas, sem precisar saber programar.

Como foi pensado

  1. Funciona sem internet

    Depois da primeira visita, os jogos e as páginas ficam guardados no aparelho e abrem mesmo sem conexão. Dá para instalar como app na tela do celular.

  2. Links curtos e QR codes

    Cada jogo tem um endereço que dá para ditar ou escrever no quadro, como …/Codigo-Mirim/ninja, e um QR code grande para projetar. Os links também vão direto para o WhatsApp e o Google Classroom.

  3. Pronto para imprimir

    Roteiro, folhas de atividades, mapas das fases e certificados saem em PDF tamanho A4, gerados a partir das próprias páginas.

  4. Sem cadastro

    Nenhum jogo pede login, e o site não coleta dados das crianças. É abrir e jogar.

  5. Acessível

    Cores com contraste conferido, zoom liberado e áreas de toque maiores nos jogos mais rápidos.

  6. Simples de manter

    HTML, CSS e JavaScript, sem frameworks e sem servidor: o site inteiro é publicado de graça no GitHub Pages.

Por dentro

Meu papel

Desenvolvo o Código Mirim: o site, os jogos, os materiais da aula e a Oficina de Prompts. O jogo Robô pega a estrela é de Paulo Severo, e os outros jogos seguem o mesmo estilo. O projeto é feito com o curso de Engenharia de Software da UNIPAMPA, no Campus Alegrete.

O Código Mirim segue em desenvolvimento: novos jogos e materiais vão entrando no site, e os que já existem continuam sendo melhorados.
